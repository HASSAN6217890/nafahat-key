# NafahatKey — كيبورد نفحات

**فرع العمل: chatgpt-v0.3** — تطوير Java أصلي لـ Android InputMethodService.

هذا الفرع مستقل عن main. المرجع النهائي: [SPEC v0.3](docs/SPEC_v0.3.md).  
تقرير الحالة التفصيلي: [V0.3_IMPLEMENTATION_REPORT.md](docs/V0.3_IMPLEMENTATION_REPORT.md).

## المعمارية

- KeyboardLayout: توزيع المفاتيح كبيانات، عربي SwiftKey/إنكليزي/رموز/أرقام.
- CanvasKeyboardView: لوحة مرسومة واحدة، أحداث لمس متعدد، معاينة وضغط مطوّل داخل العرض.
- KeyboardEngine: composing، حساسية الحقول، Enter، Shift/Caps، اقتراحات وتراجع.
- Lexicon/LearningModel: 50,000 كلمة عربية و30,000 كلمة إنكليزية مدمجة وقت البناء، مع أوزان محلية فقط.
- LibraryDb: مكتبة SQLite مع انتقال آمن من SharedPreferences في 0.2، ونسخة JSON محلية قبل التغييرات.
- MainActivity: الإعدادات والمعاينة وإدارة النصوص واستيراد محادثات واتساب وتصدير/استيراد المكتبة.

## البناء

المواصفات: minSdk 26، targetSdk 34، compileSdk 35، Android Gradle Plugin 8.7.3، Java 17.

افتح المشروع بـAndroid Studio، أو استخدم GitHub Actions في الفرع: **NafahatKey v0.3 Native Android**. يبني الـCI نسخة Debug ويجري اختبارات المصدر وJava. القواميس تُجهّز وقت البناء من wordfreq؛ **لا توجد تبعية Python على الجهاز**.

لتفعيل الإصدار Release الموقّع، اضبط GitHub Actions Secrets بالأسماء التالية دون مشاركة قيمها أو وضعها في الكود:

- NAFAHATKEY_KEYSTORE_B64
- NAFAHATKEY_STORE_PASSWORD
- NAFAHATKEY_KEY_ALIAS
- NAFAHATKEY_KEY_PASSWORD

عند توفر الأربعة، يبني CI ملف app-release.apk الموقّع، ويخطط لنشره باسم NafahatKey.apk في apk-builds. لا تعتبر النشر ثابتاً قبل معالجة تعارضه مع سير العمل القديم في main.

## الخصوصية

لا INTERNET، ولا صلاحيات جديدة، ولا تسجيل ضغطات المفاتيح أو حفظ ملف المحادثة المستورد. التخزين المحلي للقاموس الشخصي يقتصر على عدد مرات ورود الكلمات والثنائيات. كل عملية استيراد من واتساب تسأل أولاً عن اسم المرسل الذي يمثل صاحب الهاتف، ولا تستخرج رسائل الآخرين عمداً. قيود الحقول الحساسة تمنع الاقتراحات والتعلّم وعرض المكتبة.

## الحدود الحالية

الكود ليس ادعاءً بأن التطبيق خضع لاختبار أداء أو قبول على هاتف حقيقي. راجع جدول البنود 0–14 في تقرير التنفيذ؛ بعض وظائف v0.3 ما زالت جزئية، خصوصاً البحث داخل المكتبة، تعبئة القوالب، وصول TalkBack، والتحقق من التثبيت بالتوقيع الثابت.
